# TengWear NFC

本仓库**仅提供 APK 发布，不开放源代码**。

手表端用 Jetpack Compose + Wear Material 3 Expressive 重写，卡面浏览为 TENGmusic 同款「专辑流 Cover Flow」（3D 旋转 + 镜像倒影 + 表冠翻页 + 居中信息栏）。

| 文件 | 说明 |
|---|---|
| `p_手机读卡端_卡片写入与管理_v2.2.apk` | 手机端：读卡自动写入手表为卡面；拉取/启用/删除手表卡面 |
| `w_手表模拟端_Compose专辑流M3E卡面_v2.2.apk` | 手表端（Wear OS 3+）：Compose + M3E 专辑流卡面，独立换图/改名/删除/切换模拟，NDEF Type-4 标签模拟 |

## 使用

1. 手表与手机连接同一 Wi-Fi；
2. 打开手表端 App，专辑流中左右滑动/表冠翻动卡面，点按居中卡面进入编辑（使用中/换图/换色/改名/删除）；
3. 手机端选中手表 → 碰卡即写入新卡面；点按列表项=设为使用中，长按=删除；
4. 使用中的卡面即为手表模拟的数据（NDEF 文本 + 自定义 AID 规则）。

- 手机版安装：`adb install p_手机读卡端_卡片写入与管理_v2.2.apk`
- 手表版安装：`adb -s <手表IP>:5555 install w_手表模拟端_Compose专辑流M3E卡面_v2.2.apk`

> 仅供自有设备与自有卡片的实验研究，禁止用于冒用他人卡片或绕过第三方应用安全机制。
