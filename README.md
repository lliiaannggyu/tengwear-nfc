# TengWear NFC

本仓库**仅提供 APK 发布，不开放源代码**。

| 文件 | 说明 |
|---|---|
| `p_手机读卡端_局域网读卡下发_v1.0.apk` | 手机读卡端：ReaderMode 读卡，经局域网下发数据 |
| `w_手表模拟端_局域网HCE卡模拟_v1.0.apk` | 手表端（Wear OS 3+）：HCE 卡模拟，动态 AID |

## 使用

1. 手表与手机连接同一 Wi-Fi；
2. 打开手表端 App 等待配置；
3. 手机端选中手表并读卡；
4. 数据自动下发，手表靠近读头模拟。

- 手机版安装：`adb install p_手机读卡端_局域网读卡下发_v1.0.apk`
- 手表版安装：`adb -s <手表IP>:5555 install w_手表模拟端_局域网HCE卡模拟_v1.0.apk`

> 仅供自有设备与自有卡片的实验研究，禁止用于冒用他人卡片或绕过第三方应用安全机制。
